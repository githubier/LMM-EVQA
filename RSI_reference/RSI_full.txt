二、数据准备

输入数据划分为：

1. Train Set
- 用于总结和更新 ECR 预测维度。

2. Validation Feedback
- 用于计算预测指标、分析错误并指导下一轮优化。

3. Validation Selection
- 用于独立验证候选方案是否真正提升。

4. Test Set
- 迭代过程中冻结；
- 最终方案确定后只评估一次。

该阶段由以下组件完成：

Python Controller
LangBridge 开发机

主要职责：

- 数据读取；
- 固定数据划分；
- 数据隔离；
- 运行状态管理。

Qwen3.8-Max

九、候选方案验证

候选方案使用相同的 ECR Predictor 再次执行预测：

- VideoLLaMA2-7B，运行于 LangBridge 开发机；
- 或 Qwen2.5-VL，运行于 LangBridge 开发机。

分别在以下数据上评估：

1. Validation Feedback
- 检查候选方案是否带来开发集增益。

2. Validation Selection
- 独立验证候选方案是否真正泛化。

使用：

Python Controller
运行于 LangBridge 开发机

执行 Acceptance Gate，主要判断：

- Feedback 指标是否提升；
- Selection 指标是否提升或至少不退化；
- Correct 是否优于 Shuffled；
- Correct 是否优于 Constant；
- 单个 Predictor 是否明显退化。

十、接受或回滚

如果通过 Acceptance Gate：

ACCEPT

- Candidate Rubric 成为新的 Best Rubric；
- Candidate Strategy 成为新的 Active Strategy；
- 记录本轮成功经验；
- 进入下一轮 RSI。

如果未通过 Acceptance Gate：

REJECT AND ROLLBACK

- 恢复上一轮 Rubric；
- 恢复上一轮预测策略；
- 恢复上一轮 Prompt；
- 记录失败原因；
- 进入下一轮 RSI。

ACCEPT 和 REJECT 两条路径都循环返回到：

“Dynamic Prediction Prompt Construction”

或：

“ECR Prediction”

十一、停止与最终测试

每轮结束后检查停止条件：

- 是否达到最大迭代轮数；
- 是否连续多轮没有提升；
- 是否达到目标指标；
- 是否达到预算上限；
- 是否人工决定停止。

如果继续：

进入下一轮 RSI。

如果停止：

1. 冻结最佳 Rubric；
2. 冻结最佳预测策略；
3. 冻结最佳 Prompt 和 Predictor 配置；
4. 解锁 Test Set；
5. 在 Test Set 上只评估一次；
6. 输出最终 SRCC、PLCC、Final Score 和 RSI 经验。
